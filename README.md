# Factory Funner · 房间对战

使用用户提供的 Tabletopia 资源制作的响应式网页游戏。默认进入房间大厅，支持 2–6 人联机对战与游客观战，适配电脑和手机浏览器，不需要账号或数据库。

## 启动

安装 Node.js 20 或更高版本。在项目目录运行：

```powershell
node server.mjs
```

打开 http://localhost:4173 。无需安装 npm 依赖，也可以运行 `npm start`。

手机与电脑连接同一 Wi-Fi 后，用手机浏览器访问 `http://电脑的局域网IPv4地址:4173`。可用 `ipconfig` 查看电脑地址。如果 Windows 防火墙询问，允许 Node.js 在专用网络访问。大厅展示同一服务器上已创建的房间，可直接进入观战，再设置名称入座。

当前界面默认要求房间服务，必须用 Node 服务器启动；静态托管或离线缓存无法创建、加入或进行对局。不要直接双击 HTML。修改端口可设置 `PORT` 环境变量。

## 多人对战

1. 一台电脑运行 `node server.mjs`，所有玩家访问这台服务器的网页。
2. 从大厅创建房间或选择已存在的房间。加入时默认以「游客xxxxxx」身份观战，比赛中也可加入观战。
3. 点击「设置名称并入座」，设置自己的名称后成为选手。好友可输入六位房间码加入，也可使用邀请链接。电脑上的 `localhost` 链接需要换成电脑的局域网 IP，才能供手机或其他电脑访问。
4. 2–6 人到齐后，房主点击「开始对战」。每人分配独立 A 面和八张暗牌，起始资金 $10。每轮全员点击准备后倒计时，各翻一张到共享区，先点先得且不可换机。
5. 选卡限时 30 秒，时间到自动随机分配剩余卡，超时分配者不拿首末标记、不额外加分。全体选机后进入每轮 5 分钟的施工阶段，完成安装或放弃后锁定提交，在线选手完成后推进。八轮后按资金 + 连锁奖励排名，同分并列。

采用项目所引 [Tabletopia 四页原版规则](https://c.tabletopia.com/games/factory-funner/rules/factory-funner-rulebook/en) 的标准实时模式：第 2–8 轮首抢 −$1、末抢建成 +$1；双人只用末抢标记。首轮没有标记。抢到却不建通常罚 $2，最后一台放弃免罚，首抢费用仍收。剩余玩家均选择不主动抢选时，多台剩余机器随机分配，无标记、弃建免罚；若只剩一台，按末台领取处理。服务器使用同一规则引擎校验布局、锁定历史机器并计算收入，客户端不能直接指定分数。

- 刷新当前标签页可恢复身份及本轮草稿；暂时断线自动重连，断线时暂停编辑。身份保存在当前标签页的 sessionStorage，请保留原标签页。
- 无实际操作 2 分钟，或断连 15 秒，视为离线；后台轮询不计为操作。其他在线选手均完成时自动跳过离线选手，返回并实际操作后可继续当前轮。主动离开则本场退出，不能重新入座，可重新加入观战。
- 退出房间返回大厅，原有单人存档保留但不作为默认入口；房间对局不能导入单人存档或随意切换棋盘。
- 房间保存在服务器内存中，服务器重启会清空，24 小时无活动会过期。联机需要服务器持续运行；离线时仅能看到缓存页面，无法进行房间对局。跨互联网联机需把此 Node 服务部署到所有玩家能访问的地址。

- 施工稿自动同步到服务器。施工超时时，最新稿无效则直接跳过；有效则冻结，并给一次 20 秒选择保留或跳过的机会，不选择则跳过。超时后上传的改动不能替换被冻结的局面。
- 「5 分钟」当前按每轮施工时间处理，选卡时间单独计算。

详细核对记录见 [多人规则对照](docs/MULTIPLAYER-RULES.md)。

## 已实现

- 单人八回合：48 台原版机器无重复随机抽取 8 台，相同种子可复盘。
- 六种原版 A 面：各有 41 个可用格，按原图分别标定边缘墙壁；预览、切换布局、放置和划线铺管使用同一份格子数据。
- 左侧机器卡与组件仓库可直接拖入棋盘，预览合法落点并自动选中新组件；仍可点击选择后放置。
- 直接拖动管道、储罐与本轮机器；非法落点保持原位，支持撤销。
- 按住右键划线铺管，自动按六边形进出边选择管型；手机可开启“划线铺管”后拖动。整条线一次撤销，遇到非法路径全部取消。
- 原版机器与储罐美术；11 种基础管道拓扑，支持旋转、镜像与同格独立交叉。
- 图结构校验：颜色、机器输入量 / 输出量、断路、自回流、禁止供应罐与机器产物合流。
- 每色一个供应罐（六方向可选供料）、三个白罐、无限黑罐。
- 按确认时最终布局计算建造支出、机器收入、终局机间连锁奖励、历史机器位置锁定。
- 单人跳过本轮不罚款；多人按抢选身份计算弃建费用，并撤销该轮全部布局改动。
- 撤销 / 重做、连接诊断、账本、48 张机器图鉴。
- 12 章新手教程：目录跳转、前后翻页、连接示意、流量与计费例子、特殊端口、常见错误和自检问答；机器卡章节用六张卡讲解不同端口类型。
- 「重置本轮」恢复本轮开始的布局与零待确认支出，保持当前机器、回合、资金不变；误按可撤销。
- 浏览器自动存档、JSON 导出 / 导入、本机最高分。
- 鼠标 / 触控、棋盘固定自动适应、键盘快捷键。
- 本地或 HTTPS 首次完整加载后缓存应用与所有游戏必需素材，可离线继续。普通局域网 HTTP 不提供 Service Worker，电脑服务器需保持运行。

## 操作

默认入口为大厅；可从顶部「新手教程」查阅工厂连接教程，从大厅「游戏规则」查看房间限时玩法。阅读不改变当前局；「继续当前对局」返回棋盘，不再提供单独的新手关卡。当前页面会记住上次查看的章节，刷新后从第一章开始。

1. 点击本回合机器，再点击棋盘空格放置。
2. 从仓库选择储罐或管道，调整方向并放置。相邻端口可直接连接。
3. 可按住右键划过一串格子，松开后一次铺设；从机器或储罐开始/结束时须对准接口。空格起终点延伸为直管端点，可继续接设备。经过已有管道的同一接口会升级管型，经过空闲边则独立交叉。
4. 选中管件后再次点击已有管道的格子即可叠放；接口冲突时会自动寻找可用朝向。各条管道独立取色，交叉处以跨桥显示，同一格最多容纳三条双口管，不能共用接口。
4. 点击「取消选中」后可检查组件。同格多条管道在棋盘下方分别列出，可逐条选中、旋转或拆除，也可重复点击格子切换选择。
5. 检查全部连接后点击「完成安装」。八轮后自动计算总分。

可直接拖动组件到另一格；同格多条管道先在工作台选定要移动的一条。历史机器按规则固定。

快捷键：`R` 旋转，`F` 镜像管道，`Delete` 拆除，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，`Esc` 选择模式。棋盘固定自动适应屏幕；旋转、镜像和拆除按钮位于棋盘上方。

## 验证

```powershell
node --test tests/*.test.mjs
```

自动测试覆盖多人房间权限、人数上限、共享牌池、同时争抢、随机分配、首末标记、弃建罚款、同步结算、重复提交、布局校验、退出与房主转移、离线移除、过期和 HTTP 接口，以及单人拖动移动、划线铺管、流量明细、六种 A 面的格子、墙壁和存档，以及管道旋转自动跳过冲突角度、连接、相邻异色供应罐、实际管道混色、彩虹输出自动匹配、Rebuilder 二级输入自动匹配、流量不足、交叉、自回流、多台机器组成的生产循环及结算拦截、最终布局计费、库存、锁定、重置本轮、跳过、存档和终局。

Rainbowrisor / Rebuilder 根据整个连通管路的颜色约束自动选择一种兼容颜色，不需要手动设置。改接后即时重新匹配，旧存档中的手动颜色不再限制连接。若没有共同可用颜色则报错；不能用不同颜色混合满足同一端口。

`tools/browser-smoke.mjs` 使用 Playwright + Edge，在 1440px 桌面与 390px 触屏视口中执行完整操作流程：安装、旋转、撤销 / 重做、刷新恢复、导出 / 导入、八回合完成、重复查看终局、离线刷新和横向溢出检查。先启动服务器，再运行该脚本；测试工具本机路径作为回退，其他环境需自行安装 Playwright。运行时游戏无第三方依赖。

`tools/crossing-smoke.mjs` 通过电脑点击与手机触控测试同格叠管、自动调整方向、双色独立显示、跨桥绘制、三管上限、单层拆除、撤销和刷新恢复。

`node tools/tutorial-smoke.mjs` 在 1440px、390px 和 320px 视口验证全部 12 章、阅读不改存档、目录和翻页、普通随机开局、六张机器卡示例、旧存档兼容及桌面离线查阅，并在 `test-results/` 输出截图。运行前先启动服务器。

`node tools/multiplayer-smoke.mjs` 自动启动独立测试服务器（默认 4175 端口），以桌面与手机浏览器验证创建 / 邀请 / 加入、八回合同步、提交锁定、刷新恢复、断线重连、抢牌归属、首末标记与弃建费用、单人存档隔离以及 320px 布局；截图输出到 `test-results/`。使用与其他冒烟脚本相同的 Playwright + Edge 环境。

`node tools/lobby-timeout-smoke.mjs` 使用独立测试服务器及可控时钟，在真实桌面 / 手机浏览器中验证大厅发现、游客观战、实名入座、服务器草稿同步、30 秒分卡、5 分钟超时、保留最新局面与一次机会过期，无需真实等待五分钟。

## 目录

- `src/data.js`：48 台机器端口、收入、印刷可选色、管道与棋盘数据。
- `src/boards.js`：棋盘目录及六种 A 面的布局。
- `src/routing.js`：划线与六边形相交计算、批量铺管及管型升级。
- `src/engine.js`：独立于 DOM 的状态与规则引擎。
- `multiplayer.mjs`：HTTP 接口与请求校验。
- `room-service.mjs`：大厅、观众 / 选手身份、限时、活动判定、回合同步。
- `multiplayer-layout.mjs`：服务端草稿与布局校验。
- `src/multiplayer.js`：房间界面、轮询重连与独立联机草稿。
- `src/app.js` / `src/style.css`：SVG 棋盘、操作界面、存档与响应式布局。
- `src/tutorial.js`：完整规则教程内容、示意图与机器卡示例。
- `assets/game/`：资源包中切出的原版前面贴图。
- `assets/provenance.json`：素材名称与原图集裁切坐标。
- `tools/import_tabletopia.py`：从 Unity 包的 TextAsset 图集重建素材。需 UnityPy 与 Pillow，仅提取素材时使用。
- `docs/ASSETS.md`：素材来源与当前实现边界。

## 当前边界

当前提供六种原版 A 面，可从棋盘标题或工厂菜单预览与切换。切换板面必须确认重新开局，清空布局、恢复初始资金并从第一回合开始；预览或取消不影响当前对局。管道采用矢量绘制以明确表达逻辑连接，未逐一复刻原版管道的立体外观。机器数值按 48 张贴图人工录入；英文名称是显示标签，规则以端口颜色、点数、数值与方向为准。

尚未进行真实 iPhone / Android 硬件测试；手机操作已在浏览器触屏模拟中验证。多人模式已进行双浏览器同步与断线恢复测试。

游戏设计：Corné van Moorsel；原版美术与素材归原权利人所有。规则参考：[Tabletopia 原版规则](https://c.tabletopia.com/games/factory-funner/rules/factory-funner-rulebook/en)。
端口标记默认关闭，可在棋盘下方手动开启。
